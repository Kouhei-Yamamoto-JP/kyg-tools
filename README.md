# X 表示名改行ツール

X（旧 Twitter）の**表示名**に改行を入れるための静的 Web ツールです。  
[tools.ic731.net の改行ツール](https://tools.ic731.net/twitter/new_line/)と同様に、改行位置に Unicode **Line Separator（U+2028 / LSEP）** を挿入し、結果をコピーして X の設定に貼り付けます。

## 使い方

1. **入力** — テキストエリアに表示名を入力し、改行したい位置で Enter を押す
2. **変換** — `\r\n` / `\n` が U+2028（LSEP）に置き換えられる（入力時に自動変換も可）
3. **コピー** — 「コピー」ボタンでクリップボードへ
4. **貼り付け** — X → 設定とプライバシー → あなたのアカウント → アカウント情報 → 表示名 に貼り付けて保存

### 注意

- 改行の**直前・直後のスペース**があると、X 側で改行が表示されないことがあります。スペースは避けてください。
- 表示名の文字数上限は X の仕様に従います（ツール側の `maxlength` は目安です）。

## 技術メモ

| 項目 | 内容 |
|------|------|
| 改行コード | U+2028（LINE SEPARATOR / LSEP）のみ |
| 変換対象 | `\r\n` と `\n`（および単独の `\r`）のみ |
| その他の文字 | **すべて保持**（削除・分割なし） |
| 絵文字 | OK。肌色修飾、ZWJ シーケンス、国旗、異体字セレクタもそのまま残ります。改行文字以外は一切いじりません。 |

プレビューでは LSEP を画面表示用に通常の改行（`\n`）へ置き換えて、複数行として見せています。コピーされる文字列は LSEP 入りのままです。

## ローカルで開く

ビルド不要・フレームワーク不要です。

```bash
# ファイルをブラウザで直接開く
open index.html   # macOS
xdg-open index.html   # Linux

# または簡易サーバ（クリップボード API 用に推奨）
npx serve .
# → http://localhost:3000 など
```

相対パス（`style.css` / `app.js`）のため、GitHub Pages のルート公開・`/docs` 公開のどちらでも動作します。

## GitHub Pages で公開

1. このフォルダをリポジトリのルート、または `docs/` に置く
2. リポジトリ Settings → Pages → Source を設定（Deploy from branch / `docs` フォルダなど）
3. 公開 URL で `index.html` にアクセス

`package.json` は不要です。静的ファイルのみで完結します。

## 変換の確認例

入力:

```
😎
山本
```

変換後のコードポイント（抜粋）:

- `😎` = U+1F60E（変更なし）
- その直後に **U+2028 (LSEP)**
- 続けて `山` `本` の各コードポイント（変更なし）
